## 🛠️ Tech Stack

- **React 19**
- **Vite 6**
- **Tailwind CSS 3**
- **Lucide React** (Modern feather icons)
- **Inter Typography** (Google Fonts)

## 💻 How to Run Locally

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build for production
npm run build
```
